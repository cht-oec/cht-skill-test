# EIP V2 設計與驗證紀錄

本文件僅適用 `/eip/version/v2`，不作為其他版本的設計基準。V2 直接從原版 `/eip` 建立，沒有使用其他版本的元件、樣式或設計紀錄。

## 設計來源

- 使用 `.agents/skills/chtit-uxui-guidance/SKILL.md`，版本 `0.2.0-poc.5`、catalog `2026-11-17.1`；載入 `layout,form,data-management,logo,quality` 任務需要的文件。
- 2026-11-18 實際查看使用者指定的 [中華電信官網](https://www.cht.com.tw/zh-tw/home/cht)，包含首頁識別列、企業願景區與新聞區。
- 實際觀察：白色頁首、灰色分區、深藍連結及底線式頁籤、膠囊入口與大片留白。新聞區選取文字及連結 computed color 為 `#1C4E79`，背景為 `#F5F5F5`；選取底線 4px，內容容器 max-width 為 1368px。
- V2 採上述配色、圓角入口、留白及層級，保留 EIP 原側欄與操作架構，將原三欄改為 1.1／1.2／1 比例，讓待批事項有較寬的閱讀空間。沒有加入官網的行銷文字、圖片、影片或外部服務。
- 頁首細色帶是依官網外觀調整的 Web 裝飾；四個色碼為本版視覺近似值，不是手冊規定的企業識別色或輔助圖形。

企業識別來源為 `CHT-CIS-20220622`（2022-06-22），原始手冊雜湊已由 resolver 核對。標誌與簽署保留依 PDF p.26／02.1、p.32／02.7 的圖文組合；本機黑體與 Arial fallback 依 p.22–23／01.13–01.14。UI 的官網深藍是參考網站的設計值，不冒稱為 p.21／01.12 的企業標準藍 `#215DA0`。

## 元件處理結果

- **已調整**：頁首、側欄、標題與工具列、常用功能、內容卡片及頁籤、新聞及待批列表、系統入口及分類、行事曆、浮動查詢、dialog 與表單。長文字可換行，保留原列表捲動及原生彈窗。
- **符合而沿用**：正式識別圖片、圖示、全部原文及資料、群組／頁籤切換、查詢方式、待批流程、版面排列、設定與儲存流程、原生表單驗證和事件。
- **受限制而保留**：日期、時間及 select 的平台彈出 UI 由瀏覽器提供，僅調整可控制的外框、間距與焦點，未更換原生元件。
- **另列建議**：原版表單的自訂錯誤訊息尚無逐欄 `aria-describedby` 關聯；本次保留 DOM 與驗證流程。未新增原本不存在的 loading 或業務狀態。

## 驗證結果

- 六個元件的模板與事件程式逐檔比對，除版本隔離所需的替換外，與原版一致；初始資料比對一致。
- 程式層測試 V2 的暱稱、待批事項、版面、常用功能與 dialog，不會修改原版或 V1 的狀態。同版元件仍使用同一份 V2 狀態。
- Chrome 桌面、768px、320px 檢查無水平溢出；320px 手機選單可操作，查詢 popover 位於視窗內，長表單可垂直捲動。
- 200% 文字縮放：暫將 V2 所在頁的根字級設為 32px，確認正文放大、頁首高度 168px、工具列起點 208px，無遮擋或水平溢出；放大後查詢仍可操作。測試規則已移除，沒有寫入正式建置。
- 已實測 AI 頁籤、常用功能收合與原值儲存、查詢命中及空結果、待批 dialog、事件結束時間錯誤、重複捷徑錯誤、鍵盤 Alt＋方向鍵排列與取消、側欄收合、大字與節慶模式；設定已還原。
- 實際 computed color 對比：主按鈕 8.69:1、選中頁籤 7.98:1、灰底輔助文字 5.27:1、待批分類 7.33:1、紅色數量標記 6.57:1。鍵盤焦點可見。這些抽樣不代表完整 WCAG 認證。
- `npm.cmd run build -- --preset github_pages` 通過，三個版本均產生靜態路由。
- 本次變更僅涉及 V2 入口及 V2 專用元件、資料、樣式與本文件；V3 靜態 HTML 保持空白。`git diff --check` 通過，Chrome 最終 console 未見 error／warning。

未逐項操作全部系統入口，未做跨瀏覽器及輔助科技完整驗收；本次仍是原專案的本機假資料展示，沒有連接正式 EIP API。
