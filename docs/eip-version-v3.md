# EIP V3 設計與驗證紀錄

僅適用 `/eip/version/v3`。依本次要求建立橘色主題，不參考其他網站，也不採用其他版本的設計或元件。原型為原版 `/eip`。

## 設計依據

- Skill：`.agents/skills/chtit-uxui-guidance/SKILL.md`，版本 `0.2.0-poc.5`、catalog `2026-11-17.1`；使用 `layout,form,data-management,logo,quality` 的必要指引。
- 橘色主題由本次使用者要求決定。主要操作與選中狀態使用深橘 `#B54812`，hover `#96380D`、pressed `#7C2D12`；搭配暖白 `#FFF8F2`、淺橘 `#FFF1E5`、深棕側欄 `#3D2C23` 與白色內容卡片。
- 這些為 V3 的 Web 主題值，不是企業識別手冊規定的品牌橘色。既有紅色待批數量與錯誤色保留語意，不以橘色覆蓋。
- 正式識別沿用 `public/eip/logo.png`、`logo_s.png` 的原色、比例、圖文組合。一般模式以白底放置原圖，節慶模式保留反白圖片並採深棕背景；未裁切、濾色或重製識別。一般 Logo 原尺寸 200 × 50，顯示 176 × 44。
- 識別依據為 `CHT-CIS-20220622`（2022-06-22），手冊 SHA-256 已由 resolver 核對。保留簽署組合依 PDF p.26／02.1、p.32／02.7；本機黑體及 Arial fallback 依 p.22–23／01.13–01.14。UI 配色不冒稱為 p.21／01.12 的企業標準藍。

## 元件處理結果

- **已調整**：頁首及側欄、首頁標題及工具列、常用功能、卡片及頁籤、新聞與待批清單、系統入口及分類、行事曆、浮動選單、dialog 與表單的外觀、間距及響應式。
- **符合而沿用**：全部原文、示範資料、正式圖片及圖示、原欄位與驗證、群組／頁籤／收合操作、查詢與結果、待批流程、鍵盤及拖曳排列、大字與節慶設定、原生 modal 及本機儲存流程。
- **受限制而保留**：日期、時間及 select 的平台彈出 UI 由瀏覽器提供；調整可控制的外框、標籤、間距與焦點，未更換控制項。
- **另列建議**：原版表單的自訂錯誤訊息尚無逐欄 `aria-describedby` 關聯，本次保留 DOM 與驗證。沒有新增原本不存在的 loading、權限或正式 API 流程。

## 驗證

- 六個元件的模板及事件程式與原版逐檔比對；除必要的版本隔離替換外一致。初始示範資料比對一致。
- 程式層測試 V3 的設定、待批、事件、排列、常用功能及 dialog，不會改動原版、V1 或 V2 狀態；同版元件仍共享 V3 狀態。CSS selector 範圍檢查通過。
- 35 個既有原版／V1／V2／設定／正式圖片檔案的 SHA-256 前後一致。
- Chrome 桌面、768px、320px 檢查無水平溢出。手機選單及查詢可操作，查詢 popover 位於視窗內，長事件表單可以垂直捲動。
- 200% 文字縮放：暫將 V3 所在頁的根字級調為 32px，確認正文放大、頁首高度 144px、工具列起點 168px，無水平溢出或頁首遮擋；查詢 popover 仍可使用。暫時規則已移除，沒有寫入最終正式建置。
- 已實測 AI 頁籤、查詢命中及空結果、常用功能收合與原值儲存、待批 dialog、事件時間錯誤、重複捷徑錯誤、Alt＋方向鍵排列與取消、側欄收合、大字及節慶模式；設定已還原，初始待批數保持 54。
- 實際文字對比：橘色主按鈕／選中頁籤／行事曆 5.38:1、輔助日期文字 5.76:1、淺橘底待批分類 4.86:1、深棕側欄 11.88:1、紅色數量標記 6.57:1。次要操作框線對白底 3.53:1、對暖白按鈕底 3.38:1。鍵盤焦點可見；這些抽樣不代表完整 WCAG 認證。

- `git diff --check` 通過，三個版本的靜態 HTML 各自使用本版 namespace；最終 Chrome console 未見 error／warning，桌面與手機預覽已保存。
